# **App Name**: CoursePilot

## Core Features:

- Collapsible Navigation: Displays course modules and lessons in an accordion-style sidebar for easy navigation.
- Interactive Task Viewer: Presents lesson content (lecture, quiz, video, or code) within a structured task viewer.
- Active Lesson Indicator: Highlights the currently active lesson in the sidebar for quick orientation.
- Task Navigator: Navigates users between tasks within a lesson, with appropriate boundary checks and task count display.
- Intelligent Quiz Guidance: During quiz tasks, if the student answers incorrectly, then utilize a tool (LLM) that assesses the student's submission. This tool returns a rewritten quiz question as a way to gently nudge the student to revisit material covered in the current or previous steps.

## Style Guidelines:

- Primary color: Muted violet (#9370DB) to convey sophistication and innovation.
- Background color: Very light gray (#F0F0F5) for a clean and distraction-free learning environment.
- Accent color: Soft lavender (#E6E6FA) to highlight interactive elements without overwhelming the user.
- Body font: 'PT Sans', sans-serif, for readability and a modern feel. Headline font: 'Space Grotesk', sans-serif, to give the page a techy feel.
- Simple, geometric icons to represent module types and actions.
- Two-column layout with a fixed-width sidebar (w-80) and a flexible main content area.
- Subtle transitions for accordion opening/closing and task navigation to enhance usability.
